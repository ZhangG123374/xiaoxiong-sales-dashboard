# 小熊销售看板

把销售表格拖进去，马上变成能点、能筛的数据看板，还能导出成图片贴进 PPT。

不用写公式，不用学做图。免费，不用注册，**数据不离开你的电脑**。

不想下载的话，直接打开这个网址就能用：

**https://zhangg123374.github.io/xiaoxiong-sales-dashboard/**

打开页面后，表格同样只在你的浏览器里处理，不会上传。

## 下载到电脑上用

想断网使用，或者公司电脑打不开上面的网址，可以把工具下载下来：

1. 打开 [`index.html`](index.html) 这个文件的页面。
2. 点右上角的下载按钮（一个向下的箭头，Download raw file）。
3. 双击下载好的文件，它会在浏览器里打开。不用安装，不用联网。

Windows 和 Mac 都能用。请用电脑打开，手机上用不了。浏览器用近几年的 Chrome、Edge、Safari 都可以。

## 三步用起来

1. **拖入表格**：把销售表格拖进页面，或者点"选择表格文件"。支持 xlsx、xls、csv，几个月的表可以一起拖。
2. **看板自动生成**：销售额、笔数、趋势，还有各商品、地区、销售员的排行和占比。点哪一项，整个看板就只看哪一项。
3. **导出**：
   - 图片：贴进 PPT，或发到微信群。
   - 网页：能点能筛，对方用电脑双击就能打开。
   - PDF 或打印：在打印窗口里选"存储为 PDF"。

手头没有表格，可以点页面上的"用示例数据试试"。

## 支持什么样的表格

**明细表**（一行是一笔销售记录），比如从系统里导出的订单明细、销售流水：

- 至少要有一列金额。只有单价和数量也可以，会自动相乘。
- 有日期列会多出趋势图；有商品、地区、销售员这类列会多出排行和占比图。
- 列名不用和示例一样，"实付金额""成交额""下单时间""Revenue"这些常见叫法都认得。

**交叉汇总表**，会自动展开：

- 每行一个产品，每列一个月（1月、2月……，或 2024年1月、2024-01、Jan、Feb）。
- 列是季度（Q1 到 Q4）或年份（2022、2023、2024）。
- 每行一个日期或月份，每列一个城市或产品。

**暂时不支持：**

- 两层表头的表（上面一行"华东区"，下面再分"销量 / 金额"）。
- 每个月一个工作表的文件，目前只读数据最多的那一个工作表。

## 它会自动处理的事

- 自动认列：日期、金额、数量、适合分组的列。认错了可以点"识别不对？调整"手动指定。
- 表头上面的标题行、合计行、小计行、中间重复的表头，自动跳过。
- 订单状态里的退款、取消，默认不计入销售额，可以改。
- 只有年月的表（如"2024年5月"），自动改成按月展示。
- 金额不是数字的行不计入，并告诉你跳过了几行。

## 你的表格去哪了

**哪也不去。** 读表格、计算、画图、导出，全部在你自己的浏览器里完成，没有任何服务器接收你的文件。

你可以自己验证：

- **断网试一下**：关掉 Wi-Fi，再打开下载的网页文件，拖表格进去，看板照样生成。
- **看代码**：整个工具就是 [`index.html`](index.html) 这一个网页文件，全部代码都在里面，可以直接查看。

有一点请留意：导出的**网页**里包含看板用到的数据（日期、金额、数量和分组用的列），否则对方没法筛选。发给公司以外的人之前请想一下。导出的图片和 PDF 只有画面上看得到的内容。

## 常见问题

**拖进去后提示"没有找到金额列"？**
页面上会列出它读到的列名。如果这些就是你表格里的列，在上方"金额列"里手动选一下；如果不是，说明拖进去的不是表格本身，多半是快捷方式。

**不要直接拖桌面上的快捷方式。**
图标左下角带小箭头的是快捷方式，里面没有表格内容。请点"选择表格文件"来选它，或者找到真正的表格文件再拖。

**双击后打不开，或者打开是一堆代码？**
右键这个文件，选"打开方式"，再选 Chrome、Edge 或 Safari。老版 IE 不支持。

**它把我的明细表认成了交叉表？**
点"识别不对？调整"，取消第一个勾选。
